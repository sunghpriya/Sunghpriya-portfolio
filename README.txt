SUNGHPRIYA GAUTAM — CSS RESUME WEBSITE PROJECT

Files:
- index.html: website structure and content
- style.css: separate stylesheet for visual design and layout

CSS concepts demonstrated:
- Element selectors: body, header, nav, section, footer, etc.
- Class selectors: .hero, .card, .navlinks, .timeline, .pill, etc.
- ID selectors: #about, #education, #activities, #volunteering, #skills, #contact
- Flexbox: navigation links and interest tags
- Grid: feature and activity cards
- Positioning: sticky navigation, decorative hero elements, fixed print button
- Typography, colour palette, borders, spacing, hover effects and responsive media queries
- Print stylesheet for a cleaner PDF print view

Preview:
Open index.html in a browser. Keep style.css in the same folder.

GitHub Pages:
1. Upload index.html and style.css to the same GitHub repository (same folder/root).
2. Open repository Settings > Pages.
3. Select Deploy from a branch, choose main and /(root), then Save.
4. Wait for GitHub Pages to publish and copy the live website URL.
